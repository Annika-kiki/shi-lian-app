# 微信小程序集成版本

`miniprogram-2/` 是可独立导入微信开发者工具的项目。也可直接导入仓库根目录，根目录 `project.config.json` 将小程序根目录固定为该发布目录。

该版本以 `6d66ce7` 的已验证快照为基础，整合 `8c30d1e` 的首页布局与饮食解析确认交互，并修复云端接口兼容和底部导航。保留隐私同意、云托管 Bearer 登录、其他页面及压缩图片。历史 `frontend/` 目录仍保留供参考，不是默认运行入口。

当前已部署服务不提供 `/api/food/parse`（404）。前端在该接口不存在时，以 `/api/ingredients` 的真实食材数据进行明确克数的营养估算，用户确认后走既有 `/api/meals`。无法匹配或没有克数时提示补充输入，不伪造识别结果。支持该解析接口的服务仍保留 `/api/quick-log` 确认流程。

不要部署 `main` 分支回退的 mock/X-User-Id 认证代码，也不需要为运行前端启动组员电脑上的本地后端。

逐文件校验见 `miniprogram-2-manifest.txt`，完整检查说明见 `../docs/TEAM_INTEGRATION_20261017.md`。
