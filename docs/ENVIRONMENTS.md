# 环境隔离方案

## 环境

| 环境 | 用途 | 数据 | 登录 | 允许调试接口 |
| --- | --- | --- | --- | --- |
| development | 本机开发 | 本地 SQLite 假数据 | 微信登录不可用时可模拟登录 | 是 |
| staging | 体验版和回归测试 | 独立测试数据库 | 云托管身份头登录 | 否 |
| production | 正式版 | 独立正式数据库 | 微信登录 | 否 |

测试环境和正式环境不得共用数据库、会话密钥、备份目录或 API 域名。

小程序通过 `wx.getAccountInfoSync().miniProgram.envVersion` 区分环境：

- 开发版允许用本地缓存覆盖 API 地址，便于局域网真机联调；
- 体验版只通过 `wx.cloud.callContainer` 调用固定的 staging 环境和服务；
- 正式版只读取固定的 production HTTPS 地址；
- 体验版和正式版不会采用本地缓存中的接口地址。

域名确认后，在 `frontend/config/env.js` 中填写体验版和正式版地址。

## 生产门禁

设置 `APP_ENV=production` 后，后端会在启动时检查：

- 微信 AppID、云环境 ID 已通过运行环境注入，服务公网访问已关闭；
- 会话密钥不少于 32 个字符，且不是开发默认值；
- 数据库不是 SQLite；
- CORS 没有使用通配符。
- `ALLOWED_HOSTS` 填写实际 API 域名；服务自动额外允许本机健康检查地址。

任何一项不满足时服务拒绝启动，避免开发配置被误部署。

## 密钥规则

- `.env.production.example` 只记录变量名，不填写真实值。
- 数据库密码和会话密钥只保存在部署平台的密钥管理功能中；云托管模式不需要 AppSecret。
- 不通过聊天、Git、构建日志或小程序前端传递密钥。
- 密钥创建、下载、更换和撤销均需负责人确认。
