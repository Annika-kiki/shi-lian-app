# 提交审核前真机验收

执行环境：微信体验版 + staging 后端 + staging 数据库。禁止连接 production 数据库或使用 production 密钥。

记录每项的执行人、手机型号、微信版本、基础库版本、时间、结果和截图。任何 P0/P1 失败均停止上传审核。

## 首次启动与隐私

- [ ] 清除小程序数据后首次启动，不会在同意前发起登录或业务请求。
- [ ] 未勾选协议时，“微信一键登录”和“暂不填写资料”均不会进入应用。
- [ ] 用户协议和隐私政策可正常打开、返回，主体、联系方式和日期完整。
- [ ] 勾选后可通过云托管身份登录；前端和日志不显示 OpenID 或完整会话令牌。
- [ ] 注销后回到首次页面，再次进入必须重新同意当前政策。

## 账号隔离

- [ ] 两个不同微信账号分别创建饮食、体重和训练记录，互相不可见。
- [ ] 旧会话过期后可自动重新登录，页面不会丢失或循环跳转。
- [ ] 注销账号后原令牌失效，重新登录得到空白新账号。

## 资料与体重

- [ ] 可保存昵称、性别、年龄、身高、当前体重、目标体重和目标类型。
- [ ] 小于14岁、空昵称、异常身高体重会被明确拒绝。
- [ ] 同一天重复记录体重会更新而不是新增重复记录。
- [ ] 中国时间凌晨0–8点记录日期正确。
- [ ] 无体重数据时显示空状态，不显示演示曲线。

## 饮食与食谱

- [ ] 食材目录可加载、添加和移除，未知或不足食材有清晰提示。
- [ ] 生成结果只使用用户选择的已识别食材及说明中的基础调料。
- [ ] 重复打开结果页不会持续增加服务端食谱主表记录。
- [ ] 记入饮食后首页热量和三大营养素同步更新。
- [ ] 自定义餐食不会跳转到无关食谱详情。
- [ ] 网络或保存失败时不显示“保存成功”，恢复网络后可重试。

## 训练与统计

- [ ] 推荐计划、动作列表、动作详情均可加载，安全提示可见。
- [ ] 新建训练、增加组次、勾选完成、完成训练均能持久保存。
- [ ] 日历可切换前后月份，次数、时长和训练部位汇总正确。
- [ ] 无训练记录时显示空状态，不显示固定示例数据。

## 兼容性与性能

- [ ] 至少验证一台 iPhone 和一台主流 Android 真机。
- [ ] 弱网、断网、接口500和会话401均有可理解提示，不白屏。
- [ ] 冷启动、主要页面切换、长列表滚动无明显卡顿。
- [ ] 图片无缺失；主包体积低于门禁；控制台无新增错误。

## 注销与恢复

- [ ] 注销二次确认文案明确且不会误触。
- [ ] 注销后服务端资料、体重、饮食、收藏、训练及本机缓存清除。
- [ ] staging 执行一次独立备份恢复演练，恢复库通过迁移检查和核心 API 测试。

## 发布记录

- [ ] `sh scripts/verify.sh` 通过并保存输出。
- [ ] 依赖漏洞扫描通过或有已批准的风险接受记录。
- [ ] 版本号与 `CHANGELOG.md` 一致。
- [ ] 截图、类目、隐私保护指引与实际功能一致。
- [ ] 产品负责人明确确认本次上传动作。
