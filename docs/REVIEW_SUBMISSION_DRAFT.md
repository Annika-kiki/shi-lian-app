## 功能简介

食练周期是一款普通健身与饮食记录工具。用户可以填写基础身体资料，记录体重、饮食和训练，查看统计趋势，并基于所选食材获取本地规则生成的食谱建议。产品不提供医疗诊断、治疗、处方或减重效果承诺。

首版不包含支付、会员、广告、社交、消息推送、在线大模型、手机号、定位、相机、相册或麦克风功能。

## 审核人员操作路径

1. 首次打开后阅读《用户协议》和《隐私政策》，主动勾选同意。
2. 点击“暂不填写资料”可直接进入首页；点击“微信一键登录”可继续填写资料。
3. 首页可查看今日饮食和训练概览。
4. “饮食”页可选择食材、生成食谱并记入今日饮食。
5. “训练”页可查看动作建议，进入动作详情并保存训练组次。
6. “日历”页可查看按月汇总；“我的 → 身体数据”可记录体重并查看趋势。
7. “我的 → 隐私与数据”可注销账号并删除个人数据。

无需提供审核测试账号，小程序使用审核人员本人的微信临时登录凭证创建隔离账号。正式提交前必须在体验环境验证该路径。

## 隐私声明映射

| 实际处理的信息 | 功能目的 | 触发时机 |
| --- | --- | --- |
| 微信账号对应的 OpenID | 建立隔离账号和登录会话 | 用户勾选协议并继续后 |
| 用户主动填写的昵称、性别、年龄、身高 | 展示资料并计算一般性目标 | 保存资料时 |
| 当前/目标体重及体重记录 | 趋势和目标进度 | 保存资料或记录体重时 |
| 饮食、食材和食谱记录 | 摄入统计与历史 | 用户主动记入饮食时 |
| 训练动作、组次、重量、时长 | 训练历史和消耗估算 | 用户主动完成训练时 |

首版不申请微信头像昵称授权；昵称由用户在表单中主动填写。

## 健康与内容说明

- 所有热量、营养目标和运动消耗均标注或定位为一般性估算。
- 食谱由本地规则与基础食材目录生成，不接入在线生成式人工智能服务。
- 对疾病、伤病、过敏、孕期、疼痛和其他特殊情况提示先咨询专业人员或停止运动。
