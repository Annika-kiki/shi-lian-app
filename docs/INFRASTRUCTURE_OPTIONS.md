# 低成本生产基础设施建议

核对日期：2026-09-05。实际开通价格和个人主体可用性必须在购买页再次确认。

## 推荐方案

首版保留 FastAPI，优先评估腾讯云 CloudBase 云托管 + MySQL 型数据库：

- 不重写现有 API、数据模型和测试；
- 容器制品可在测试环境验证后原样提升到正式环境；
- 与微信生态的域名和登录联调路径较短；
- 初期按最低规格和实际用量计费，流量增长后再扩容。

腾讯云当前说明云托管按实际资源和使用时间计费；其示例中，1核2GB单实例连续30天的计算刊例约57.58元，0.5核1GB约为其一半量级。MySQL 型数据库连续30分钟无访问可自动暂停，但每次启动后的最小运行时长为30分钟，仍可能产生套餐、存储和网络费用。

需要特别注意：CloudBase MySQL 当前自动备份为每天一次、保留7天，而且个人版暂不支持控制台回档。因此正式环境不能只依赖平台内置备份；若确认隐私政策采用30天备份周期，还要增加独立加密逻辑备份和恢复演练。

## 不建议首版重写为云函数

云函数在极低调用量下可能更省计算费用，但需要重写 FastAPI 路由、SQLAlchemy 数据层、迁移、部署和部分测试。当前上线目标以降低交付风险为优先，预计节省的早期费用不足以抵消重写成本。

## 成本控制

- staging 只在测试窗口运行，且使用独立的最低规格资源；
- production 初始只运行一个最低规格实例，设置费用告警和最大实例数；
- 图片继续随小程序包发布，不购买对象存储或 CDN；
- 不启用付费 AI、短信、消息推送、支付或高级审计服务；
- 先查看账号是否有免费额度、个人版套餐或新用户额度；
- 开通任何资源前记录月度费用上限并由负责人确认。

## 待后台确认

- 个人主体能否开通目标云托管和数据库套餐；
- 当前账号可用的免费额度、最低套餐及自动暂停能力；
- 云托管默认域名能否满足小程序 request 合法域名和备案要求；
- staging 与 production 两个环境的最低实际月成本。
- 个人版是否提供可用的数据库直连或导出能力，以执行独立逻辑备份。
