# 食练周期隐私政策（审核草案）

状态：待运营者确认，不能直接作为已接受的法律文本发布。

## 适用范围

食练周期是一款面向14周岁以上用户的普通饮食与健身记录工具，不提供医疗诊断、治疗或效果承诺。未满14周岁的用户请勿使用本服务或提交个人信息。

## 收集的信息和目的

| 信息 | 是否必需 | 用途 |
| --- | --- | --- |
| 微信账号对应的 OpenID | 是 | 创建账号、识别登录用户；不向小程序前端返回 |
| 昵称 | 否 | 个性化展示，仅在用户主动填写时处理；首版不申请微信昵称或头像授权 |
| 性别、年龄、身高 | 否 | 用户填写资料时，用于计算一般性营养目标和训练展示 |
| 当前体重、目标体重、体重记录 | 否 | 用户使用身体记录功能时，展示趋势和目标进度 |
| 饮食、食材和食谱记录 | 否 | 用户使用饮食功能时，计算营养摄入并展示历史 |
| 训练动作、组次、重量和时长 | 否 | 用户使用训练功能时，保存训练历史并估算运动消耗 |
| 必要的安全日志 | 是 | 排查故障、防止滥用和保护账号安全；不得记录完整会话令牌或微信 AppSecret |

首版不调用微信头像昵称授权，不收集手机号、精确位置、通讯录、相机、相册、麦克风、支付信息，也不接入广告和在线大模型。

## 使用与共享

个人信息仅用于实现上述功能、安全运维和依法履行义务，不出售个人信息，不用于自动化营销。正式托管服务商确定后，应在此列明服务商名称、处理目的、信息类型和处理方式。

## 保存与保护

在线个人数据在账号存续期间保存。传输使用 HTTPS；数据库、备份和密钥采用访问控制与隔离。建议备份保存周期为30天，周期届满自动清除，最终周期须与云平台能力和后台声明保持一致。

## 用户权利

用户可以在小程序内查看和更正资料，并在“我的 → 隐私与数据”注销账号。注销后在线个人资料、体重、饮食、收藏和训练记录立即删除，备份副本在既定周期内清除。

## 健康提示

营养目标、热量和运动消耗均为一般性估算。如有疾病、伤病、过敏、饮食障碍、孕期或其他特殊情况，应先咨询医生或具备资质的专业人员；出现疼痛或不适时应停止运动。
